GitHub reports download_count as a lifetime cumulative total per asset. It does not provide day-by-day history, so per-version figures are totals-to-date—not a time series. The version chart is the closest available adoption signal.

Public API limit: 60 requests/hour per IP without a token, or 5,000/hour with one. Filename-based platform detection is best-effort.
